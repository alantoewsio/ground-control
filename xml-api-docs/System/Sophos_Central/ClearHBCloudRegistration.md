# ClearHBCloudRegistration

- **Operation**: Clear Registration
- **Description**: To clear registration from Sophos Firewall OS.

## Sample Configuration

``` xml
<ClearHBCloudRegistration />
```

## Attribute/Parameter Information

|Parameter|Mandatory|Default|Description|
|-|-|-|-|

## Status Message Information

|Operation|Status|Message|
|-|-|-|
|Clear Registration|200|Sophos Central registration cleared|
|Clear Registration|500|Clearing registration failed|
|Clear Registration|546|Detected stand-alone node. Can't cancel registration.|
