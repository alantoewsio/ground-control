# GuestUserSettings

- Operation: Configure Guest User
- Description: Configure parameters to allow secured internet access for guest users.

## Sample Configuration

``` xml
<GuestUserSettings>
    <AllowGuestUserSettings>Enable/Disable</AllowGuestUserSettings>
    <SMSGateway>smsgatewayname</SMSGateway>
    <GuestUserSettingsName>CellNumber/AutoGenerate</GuestUserSettingsName>
    <grouplist_cat>Text</grouplist_cat>
    <smsgwprofileid_cat>Text</smsgwprofileid_cat>
    <!-- For AutoGenerate -->
    <UserNamePrefix>Username Prefix</UserNamePrefix>
    <UserValidity>
        <!-- Only one of below will be present -->
        <Days>Number</Days>
    </UserValidity>
    <AutoPurgeOnExpiry>Enable/Disable</AutoPurgeOnExpiry>
    <UserGroup>usergroupname</UserGroup>
    <CountryCode>country code</CountryCode>
    <CAPTCHVerification>Enable/Disable</CAPTCHVerification>
    <PasswordLength>Number</PasswordLength>
    <PasswordComplexity>AlphanumericPassword/AlphabeticPassword/NumericPassword/AlphaNumericWithSpecialCharacterPassword</PasswordComplexity>
    <Disclaimer>Text</Disclaimer>
</GuestUserSettings>
```

## Attribute/Parameter Information

|Parameter|Mandatory|Default|Description|
|-|-|-|-|
|AllowGuestUserSettings|No | |Description:|
||||Enable to allow secured internet access to guest users.|
||||AllowGuestUserSettings confines to:|
||||Type is 'SCALAR'.|
||||Only 'Disable', 'Enable' are allowed.|
|SMSGateway|Yes | |Description:|
||||Select the gateway to be used for sending SMS.|
||||SMSGateway confines to:|
||||Type is 'SCALAR'.|
||||Datatype is 'STRING'.|
|GuestUserSettingsName|Yes | |Description:|
||||Select the method for generating Username from the available options.|
||||GuestUserSettingsName confines to:|
||||Type is 'SCALAR'.|
||||Only 'CellNumber', 'AutoGenerate' are allowed.|
|UserNamePrefix|Yes | |Description:|
||||Specify Prefix to be used for Auto-Generation of Username.|
||||UserNamePrefix confines to:|
||||Type is 'SCALAR'.|
||||Datatype is 'STRING'.|
||||Maximum characters allowed are 10.|
|Days|Yes |7 |Description:|
||||Specify guest user validity period in days.|
||||Days confines to:|
||||Type is 'SCALAR'.|
||||Datatype is 'INTEGER'.|
||||Maximum digits allowed are 3.|
|AutoPurgeOnExpiry|No | |Description:|
||||Enable automatic purging of user details on expiry of user validity.|
||||AutoPurgeOnExpiry confines to:|
||||Type is 'SCALAR'.|
||||Only 'Enable' are allowed.|
|UserGroup|Yes | |Description:|
||||Select Group to assign to the User.|
||||UserGroup confines to:|
||||Type is 'SCALAR'.|
||||Datatype is 'STRING'.|
|CountryCode|No | |Description:|
||||Enable to configure default Country Code.|
||||CountryCode confines to:|
||||Type is 'SCALAR'.|
||||Datatype is 'STRING'.|

||||CAPTCHVerification confines to:|

||||Datatype is 'STRING'.|
