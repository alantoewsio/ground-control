    Flyouts

    View opens a right-aligned sheet (same geometry as gc-if-flyout__panel); click the content skeleton to open a secondary sheet from underneath, leaving a ~2 cm peek of the primary (the primary width resets to the default when you do). Drag the left edge of either sheet to resize; both can use the full width of the overlay. Close the stack with the secondary ×, by clicking the peek, with Escape (stack first), or by clicking the backdrop (stack first). The primary ×, Escape (when not stacked), or backdrop still close the whole flyout. Each button shows a control id underneath — use that name when requesting the same pattern on another page. Edit matches the same resizable sheets and stacked open/close motion as View: click the primary content skeleton to open a secondary sheet from underneath. The stacked secondary dismisses only with its Save or Cancel (not peek, backdrop, or Escape). The primary sheet still has no × — only its Save or Cancel closes the whole flyout (backdrop and Escape do not).

    Dialogs

    Centered modal patterns: Info (OK only), Confirm (OK primary, Cancel secondary), Approve (Yes primary, No destructive). Backdrop and Escape close the dialog. Control ids under the buttons name each variant for reuse elsewhere.

    Banners

    Banner state is stored in sessionStorage and survives refresh. A consolidated row (latest message, more ⋯, and a small aggregate progress bar for in-flight types) appears only when two or more banners of that type are active at once. A single banner uses a simpler row without ⋯ or the aggregate bar. The popover lists each item with its control id (e.g. timed-progress-banner) and message; timed progress keeps × (completes oldest); Finish still completes the oldest persistent item (FIFO). Completed/Error rows use × to clear the whole group. The control id under each demo button names the pattern for reuse elsewhere.
