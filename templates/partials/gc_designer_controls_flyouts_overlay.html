IP field properties

Validation options

Save writes data-gc-ip-* on the demo inputs (after that, validation uses those attributes). Until you Save, the fields follow the settings below. IPv4 range applies only to the IPv4 field. Use separate CIDR fields for IPv4 and IPv6 containment. With CIDR /prefix min–max, enter values as address/prefix; prefix must fall in that range (per family: 0–32 or 0–128). Must be a CIDR subnet requires host/prefix; on blur the host is normalized to the network address for that prefix (e.g. 10.1.2.3/16 → 10.1.0.0/16).
