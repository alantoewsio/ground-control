IP address fields

Dotted-quad IPv4 (aligned with interface_table._IPV4_RE). IPv6 uses bracket URL parsing (compressed forms, ::); zone identifiers after % are stripped before parsing. Use Configure IP field properties (same sheet pattern as edit-flyout on Modals) to set validation options on both fields. Until you Save in that sheet, the demo inputs follow the in-sheet settings; Save writes data-gc-ip-* on the inputs. The ip-address control uses IPFamily (IPv4 or IPv6) in catalog JSON; the demo toggles family with the select below. The label exposes gcOpenIpFieldPropertiesFlyout() to open the sheet from script.

Text fields

Single-line and multi-line inputs with minlength / maxlength. Charset presets are the distinct xml-api-docs STRING constraint sets (duplicates such as FQDNHost vs MACHost Name are merged). Use Configure text field properties for the sheet; text-single and text-multiline expose gcOpenTextFieldPropertiesFlyout().

Option selectors

One continuous control: a single outer border and pill-shaped ends (end radius is half the bar height). Segments are flush with no gap; vertical dividers separate options. The active segment uses the primary style; inactive segments use the neutral secondary look.

Toggles

On/off switch is a button with role="switch", aria-checked, and the same track/thumb classes as boolean columns in data tables (this demo uses accent blue when on; default table toggles use success green). Toggle checkbox is a real checkbox with the toolbar combine pattern: label text, visually hidden input, and sliding thumb (accent when checked) — use it when the value must post with a form or participate in native checkbox semantics.

Tags

Type to filter tag suggestions. The first match previews inline after the caret; more matches appear in a list (arrow keys, Enter to add). Tags appear as pills with remove on hover. When focus leaves, the control collapses to one line with a +N overflow pill if needed. Unsaved tags (not yet committed with Save) use black pills with white text. After save, each tag name gets a stable color (same name → same color in both editors).

      Dropdowns

      Searchable single- and multi-select lists backed by cached Hosts & Services objects. Each control has its own scope (top-bar selection vs custom firewall/configuration IDs), entity-type filters, optional list columns, and per-type icons. The filter box sits inside the open panel. Lists reload automatically when scope, custom IDs, entity types, or the top-bar firewall/configuration selection change. Load from cache repeats the fetch with current settings. Use the property buttons for shared UI, single-select source, and multi-select source; dropdown-single / dropdown-multi / dropdown-shared expose gcOpenDropdownPropertiesFlyout() (pass "shared", "single", or "multi").

          Member lookup

          Searchable single- or multi-select of cached object names (same table API as Dropdowns). Scope resolves from the Object edit flyout firewall or configuration multiselect when this control is inside #gc-designer-flyout-object-edit-modal (checked rows); if none are checked there, it falls back to the top-bar firewall/configuration selection. Use Configure member lookup to choose object types and single vs multi. The open panel always includes a filter field; multi-select adds Select all shown for the rows visible after filtering. member-lookup exposes gcOpenMemberLookupPropertiesFlyout().
