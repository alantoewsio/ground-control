Object Navigation

One row per distinct entity_type from the config cache. Only the entity type column is read-only. Nav section, Nav page, and Tab are comboboxes: type to filter or pick from suggestions. Nav page suggestions only include values from rows that share the same nav section (case-insensitive). Tab suggestions only include values from rows that share the same nav section and nav page (case-insensitive). Rows sort by saved facet order (section, then page, then tab), then nav order (numeric first; blank sorts after numbers). Use the grip next to section, page, or tab to open a short list of unique values for that scope; drag there to reorder that facet, then Apply order. Use the left row drag handle to reorder entity types within the same section, page, and tab; nav order updates automatically. While row-dragging, other rows are dimmed. Column headers do not sort the table.
